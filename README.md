# Quotation-Management-System
📌 Project Description

This is an enterprise-level web application developed using ASP.NET Core Razor Pages for managing quotation processes including enquiry, vendor details, and instrument data.

🚀 Features
Create and manage quotations
Enquiry-based quotation generation
Instrument and range selection
GST, CGST, SGST calculation
CRUD operations for quotation details
Form validation and error handling

🛠️ Technologies Used
ASP.NET Core Razor Pages
C#
Entity Framework Core
SQL Server
JavaScript
